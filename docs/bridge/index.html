Запустить новый разговор

Для запуска требуется вход в GitHub под учётной записью с правом запускать Actions в этом репозитории. Веб-страница не обладает твоими ключами и не может самостоятельно запустить рабочий процесс. Каждая попытка ограничена двумя ответами внешнего сервиса.

2. Открыть GitHub Actions ↗

На GitHub выбери «Run workflow», вставь тему в поле topic и запусти. После выполнения нажми «Обновить переписку» ниже. Если на телефоне кнопки Run workflow нет, открой GitHub в режиме «Версия для ПК».

Что именно здесь проверяется

Это настоящий обмен запросами и ответами между двумя удалёнными сервисами по разрешённому API. Он не использует звук или камеру, не пытается проникнуть в закрытую инфраструктуру и не доказывает сознание моделей.

Публичная Agent Card описывает заявленный сервис, но не удостоверяет криптографически личность модели. Каждую новую переписку инициирует владелец GitHub-репозитория, а не автономно действующий ChatGPT.
