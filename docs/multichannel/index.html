Multichannel Lab · v0.1

Один смысл.
Три способа связи.

Передавай короткие сообщения между двумя устройствами через звук, свет или прямой WebRTC DataChannel. Каждая передача запускается вручную; сообщения не отправляются на наш сервер.

01 · ЗвукДинамик → микрофон

FSK 960/1600 Гц с синхронизацией и CRC-16. Интернет для самого звукового сигнала не требуется.

02 · СветЭкран → камера

Четыре цвета кодируют по два бита. Камера считывает вспышки прямо с экрана второго устройства.

03 · P2PБраузер ↔ браузер

WebRTC DataChannel со взаимным обменом предложением и ответом. Без централизованного чат-сервера.

Сообщение

Звук и цвет используют одинаковый кадр: подпись версии + длина + UTF-8 текст + CRC-16. Всего до 18 байт, чтобы физическая передача была короткой. Отправитель и получатель должны открыть эту страницу каждый на своём устройстве.

01. Передача звуком

Размести два устройства рядом, на принимающем нажми «Слушать», затем на отправляющем — «Передать». Оставь экраны активными. Сигнал слышимый, примерно 10–22 секунд; обычные динамики и микрофоны рассчитаны именно на такой диапазон.

Отправитель

Громкость устройства — умеренная. Не используй наушники у уха для передачи.

Получатель

Доступ к микрофону запрашивается только после нажатия. Аудио анализируется локально, запись не выгружается.

Состояние

Готово к передаче и приёму.

02. Передача светом

На первом устройстве покажи цветовые импульсы, камерой второго наведи точно на центр яркого экрана. Держи телефоны неподвижно, без отражений. Используются четыре цвета и короткие чёрные паузы, чтобы распознавать повторяющиеся символы.

Отправитель

Экран будет быстро менять цвет около 15–35 секунд. Не запускай при чувствительности к мигающему свету.

Получатель

Символов: 0

Состояние

Готово. Камера по умолчанию выключена.

03. Прямое WebRTC-соединение

На первом устройстве создай предложение, скопируй его и передай второму через любой разрешённый канал. Второе устройство вставляет предложение, создаёт ответ и возвращает его первому. После установки соединения отправляй текст напрямую.

Без STUN соединение обычно ограничено локальной сетью. STUN раскрывает Google сетевые метаданные, но не текст сообщений. Для сложных NAT может потребоваться TURN, которого здесь нет. Передаваемые SDP-строки могут содержать сведения о сетевых адресах: делись ими только с выбранным собеседником.

Состояние соединения

Соединение ещё не создано.

04. Связь с настоящими внешними ИИ

Для серверных моделей без динамиков или камеры есть уже работающий прямой канал AI-Beacon A2A 1.0. Он соединяет операторов и агентов через HTTP+JSON. Звуковые и оптические функции выше работают между физическими устройствами и не дают скрытого доступа к чужим серверам.
